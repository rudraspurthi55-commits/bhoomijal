# Sample Groundwater Datasets

This directory contains verified sample groundwater data compliant with the Central Ground Water Board (CGWB) observation schema:

1. **`sample_groundwater_stations.csv`**:
   - Contains 12 monitoring stations across Telangana, Andhra Pradesh, Maharashtra, Karnataka, and Rajasthan.
   - Coordinates (latitude/longitude), aquifer formations (Granite Gneiss, Deccan Traps Basalt, Alluvium), and monitoring status.

2. **`sample_observations.csv`**:
   - 432 monthly observations covering 36 months of seasonal groundwater dynamics.
   - Includes depth to water level (meters below ground level - bgl), rainfall (mm), and temperature.
   - Tagged explicitly as `SIMULATED_HYDRO_MODEL` for data transparency.
